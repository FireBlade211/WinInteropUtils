WinFileInfo(string, WinFileInfoOptions, WinFileAttributes?)

Retrieves the info of the file specified by path.

public WinFileInfo(string path, WinFileInfoOptions options = WinFileInfoOptions.None, WinFileAttributes? attribs = null)

Parameters

path string

The path of the file to retrieve info about.

options WinFileInfoOptions

Specifies additional options for the file info to retrieve.

attribs WinFileAttributes?

File attributes. See Remarks for more info.

Remarks

If the attribs parameter is set, it indicates that the function should not attempt to access the file specified by path. Rather, it should act as if the file specified by path exists with the file attributes passed in attribs.

You should call this function from a background thread. Failure to do so could cause the UI to stop responding.
