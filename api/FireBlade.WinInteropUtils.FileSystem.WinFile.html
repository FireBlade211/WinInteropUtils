Parameters

path string

The path to the file.

access WinFileAccess

The requested access to the file. A bitwise combination of WinFileAccess values.

shareMode WinFileShareMode

The requested sharing mode of the file.

mode WinFileOpenMode

The action to take on a file that exists or does not exist.

attribs WinFileAttributes

The file attributes and flags.

options WinFileOptions

Additional options for opening the file.

templateFile WinFile

A valid template file with the Read access right. The template file supplies file attributes and extended attributes for the file that is being created. If opening an existing file, this parameter is ignored.
