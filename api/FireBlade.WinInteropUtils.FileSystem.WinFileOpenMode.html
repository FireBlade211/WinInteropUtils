Specifies how to open a WinFile.

public enum WinFileOpenMode
Extension Methods
EnumExtensions.GetValues(Enum)

Fields

CreateAlways = 2

Creates a new file, always. If the specified file exists and is writable, the file is truncated.

CreateNew = 1

Creates a new file, only if it does not already exist. If the specified file exists, WinFile throws an IOException.

OpenAlways = 4

Opens a file, always. If the specified file does not exist and is a valid path to a writable location, the file is created.

OpenExisting = 3

Opens a file or device, only if it exists. If the specified file does not exist, WinFile throws a FileNotFoundException.

TruncateExisting = 5

Opens a file and truncates it so that its size is zero bytes, only if it exists. If the specified file does not exist, WinFile throws a FileNotFoundException.

The calling process must open the file with Write bit set as part of the shareMode parameter.
